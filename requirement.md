This is a critical requirement.

I like Imagicaa's visual experience but do not want a heavy website.

The objective is:

**Imagicaa-level visual appeal with significantly better loading performance.**

Instead, optimize the implementation.

## Core Web Vitals targets

- LCP: 2.5 seconds or less.
- INP: 200 ms or less.
- CLS: 0.1 or less.

## Image optimization

- Use WebP or AVIF.
- Use responsive image sizes.
- Use appropriate compression.
- Specify image dimensions.
- Lazy-load below-the-fold images.
- Prioritize the main hero image.
- Use Next.js Image optimization where appropriate.
- Avoid unnecessarily large desktop images on mobile.

## Frontend optimization

- Minimize unnecessary JavaScript.
- Use code splitting.
- Optimize fonts.
- Use efficient caching.
- Avoid excessive dependencies.
- Minimize third-party scripts.
- Avoid unnecessary autoplay videos.
- Prefer lightweight CSS animations.
- Avoid excessive parallax.
- Prevent layout shifts.

Do not lazy-load the main hero image unnecessarily.

Test with:
- Lighthouse.
- Google PageSpeed Insights.
- Mobile performance testing.

Report actual measured results, not assumed scores.
